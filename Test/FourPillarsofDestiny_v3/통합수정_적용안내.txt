사주 서비스 통합 수정본 적용 안내
================================

이번 압축본은 이전의 작은 패치를 다시 겹쳐 쓰는 용도가 아니라,
현재 요구사항을 하나로 정리한 통합 기준본입니다.

1. 가장 먼저 현재 프로젝트 폴더를 통째로 백업해 주세요.

2. 이 압축본의 파일을 기존 프로젝트 루트에 같은 경로로 덮어씁니다.

3. 중요: 기존 data 폴더는 삭제하지 마세요.
   - 기존 원국 수집 자료(result.html / result.txt / network.json 등)를 그대로 보존합니다.
   - 이번 버전은 파서 버전이 바뀌면 저장된 원문을 먼저 다시 읽어
     신강·신약, 신살·길성 위치, 대운 등을 재파싱합니다.
   - 따라서 이미 수집한 사람을 무조건 웹에서 다시 조회할 필요가 없습니다.
   - data/runtime_metrics.json도 유지하면 예상 소요시간 보정 이력이 유지됩니다.

4. 이전에 받은 소규모 patch ZIP은 이 기준본 위에 다시 덮지 마세요.
   서로 다른 버전의 HTML/JS/CSS/이미지가 섞이면 UI가 다시 깨질 수 있습니다.

5. 적용 후 검수:

   python verify_project.py

   VERIFY OK가 나오는지 확인해 주세요.

6. 서버를 완전히 종료했다가 다시 실행합니다.

   "C:/Program Files/Python313/python.exe" app.py

7. 브라우저에서 Ctrl + F5로 강력 새로고침합니다.

8. 로컬 통합 테스트 화면:

   http://127.0.0.1:8787/test

   /test는 localhost 전용이며 일반 서비스 화면에는 테스트 인물 정보가 노출되지 않습니다.

이번 통합 수정의 핵심
---------------------
- 사용자 본문은 사주 전문용어/퍼센트보다 실제 생활 의미를 먼저 설명
- 직장 그룹에서는 애정·호감·데이트·배우자 같은 연애 문구 사용 금지
- 연인 궁합에서는 각자 원하는 관계 방식, 애정 표현, 연락, 돈, 개인시간, 갈등 회복까지 구체화
- 친구/가족/동호회/직장 그룹은 관계 유형별로 서로 다른 해설과 운영 팁 사용
- 1:1과 자동 궁합에서 본인과 상대 원국을 함께 표시
- 자동 궁합 TOP 후보는 왼쪽/상단 순위 목록과 상세 화면을 동시에 유지하고 이전/다음 탐색 지원
- 그룹은 핵심 연결 → 관계도 → 매트릭스 → 추천 역할 → 1:1 상세 순으로 탐색 가능
- 그룹 결과 빠른 이동 메뉴와 이름 검색/정렬/지연 렌더링 제공
- 원국 표시는 모든 화면에서 시주 → 일주 → 월주 → 연주로 통일
- 신강·신약, 신살·길성 및 위치, 대운을 저장된 Forceteller 원문에서 재파싱
- 올해/이번 달/오늘 운세는 서로 다른 시간 범위와 생활 초점으로 생성하며 동일 문장 재사용 방지
- 문장 글자 수 강제 절단 제거 및 카드/원국/로딩/상세 영역 overflow 보정
- 실제 A1 토끼 PNG를 주요 브랜드/로딩 영역에서 사용
- CSS/JS/이미지 캐시 버전 통일

주의
----
이 프로젝트는 명리 전통 해석을 구조화한 서비스이며 과학적 예측이나 관계 성공확률을 제공하는 서비스가 아닙니다.
